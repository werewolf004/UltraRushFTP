# Dependencies

**English** | [Français](DEPENDENCIES.fr.md)

UltraRushFTP depends on **22 crates directly** and **374 crates in total** (Windows,
transitive dependencies included). The complete list with versions and licences is
generated by `scripts/generate-dependencies.ps1` into
[dependencies-full.md](dependencies-full.md); CI fails when it is out of date.

## Rules

- **Licences**: only permissive licences compatible with distributing a proprietary
  binary are accepted (MIT, Apache-2.0, BSD-2/3-Clause, ISC, Zlib, CC0-1.0, Unicode-3.0,
  BSL-1.0, CDLA-Permissive-2.0), checked by `cargo deny` on every push (`deny.toml`). One
  scoped exception: the fonts embedded by egui (`epaint_default_fonts`, OFL-1.1 and Ubuntu
  Font Licence), which allow bundling.
- **Notices**: every release ships `THIRD-PARTY-LICENSES.txt`, the licence texts of all
  runtime dependencies (`generate-dependencies.ps1 -Notices`).
- **Advisories**: RustSec advisories fail the build. Documented exceptions in `deny.toml`:
  - `RUSTSEC-2024-0436` — `paste` is unmaintained; compile-time macro of `egui_dock`, no
    runtime code.
  - `RUSTSEC-2023-0071` — `rsa` (Marvin timing attack), pulled by `russh` for SSH RSA keys;
    no fixed version exists. Only the signature with a local RSA key is concerned; ed25519
    and ECDSA keys are not. Kept by decision of 2026-11-05; prefer ed25519 keys.
  - `RUSTSEC-2026-0543` — `chrono` is unmaintained (no known vulnerability), pulled by
    `russh-sftp` for the dates of SFTP listings; no replacement version.
- **Sources**: crates.io only (no git or alternative registry).
- **Versions**: `Cargo.lock` is committed and builds use `--locked`; Dependabot proposes
  updates weekly.

## Software rendering pack

Not a dependency of the program: an optional download of each release for Windows without
Direct3D 12. `scripts/package-software-render.ps1` takes `opengl32.dll` from
[mmozeiko/build-mesa](https://github.com/mmozeiko/build-mesa) (Mesa llvmpipe 26.3.0, LLVM
linked in), checks the SHA-256 written in the script and zips it with
`packaging/software-render/` (instructions, Mesa MIT licence, LLVM Apache-2.0 with LLVM
exceptions). The DLL is never in the repository, the zip or the installer of the program.
